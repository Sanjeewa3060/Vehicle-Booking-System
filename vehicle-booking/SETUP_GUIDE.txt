SETUP INSTRUCTIONS:
================================================================================

1. DATABASE SETUP:
   
   Run these SQL commands:
   
   CREATE DATABASE vehicle_booking;
   
   USE vehicle_booking;
   
   CREATE TABLE users (
     id INT AUTO_INCREMENT PRIMARY KEY,
     name VARCHAR(100) NOT NULL,
     email VARCHAR(100) UNIQUE NOT NULL,
     password VARCHAR(255) NOT NULL,
     role ENUM('user', 'admin') DEFAULT 'user',
     status ENUM('active', 'inactive') DEFAULT 'active',
     created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );
   
   CREATE TABLE vehicles (
     id INT AUTO_INCREMENT PRIMARY KEY,
     name VARCHAR(100) NOT NULL,
     type VARCHAR(50) NOT NULL,
     price DECIMAL(10,2) NOT NULL,
     status ENUM('Available', 'Booked') DEFAULT 'Available',
     created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );
   
   CREATE TABLE bookings (
     id INT AUTO_INCREMENT PRIMARY KEY,
     user_id INT NOT NULL,
     vehicle_id INT NOT NULL,
     start_date DATE NOT NULL,
     end_date DATE NOT NULL,
     status ENUM('Active', 'Completed', 'Cancelled') DEFAULT 'Active',
     created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
     FOREIGN KEY (user_id) REFERENCES users(id),
     FOREIGN KEY (vehicle_id) REFERENCES vehicles(id)
   );

API TESTING WITH CURL:
================================================================================

1. LOGIN AND GET TOKEN:
   
   curl -X POST http://localhost/vehicle-booking/api/auth/login.php \
     -H "Content-Type: application/json" \
     -d '{"email":"john@test.com","password":"password"}'
   
   Response will include a JWT token.

2. GET VEHICLES:
   
   curl http://localhost/vehicle-booking/api/vehicles/list.php

3. GET USER STATS (Requires Token):
   
   curl -H "Authorization: Bearer YOUR_JWT_TOKEN" \
     http://localhost/vehicle-booking/api/user/dashboard-stats.php

4. CREATE BOOKING:
   
   curl -X POST http://localhost/vehicle-booking/api/bookings/create.php \
     -H "Authorization: Bearer YOUR_JWT_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"vehicle_id":1,"start_date":"2026-01-25","end_date":"2026-01-27"}'

================================================================================
TROUBLESHOOTING:
================================================================================

Issue: "Connection error" when accessing API
Solution:
  - Check database connection in api/config/database.php
  - Verify MySQL service is running
  - Check database credentials

Issue: "Unauthorized" error
Solution:
  - Ensure JWT token is included in Authorization header
  - Verify token hasn't expired (7 days)
  - Check browser console for token issues

Issue: "Forbidden: Admin access required"
Solution:
  - Only admin users can access admin endpoints
  - Create admin account or promote user to admin role

Issue: CORS errors
Solution:
  - Check api/config/cors.php headers
  - Verify API_URL in js/config.js matches your server

Issue: JavaScript errors in console
Solution:
  - Clear browser cache
  - Verify all JS files are loading (F12 → Network tab)
  - Check for syntax errors in console
